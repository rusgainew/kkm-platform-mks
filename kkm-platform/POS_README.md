# POS-система (Кассовый терминал)

Прототип интерфейса централизованного кассового терминала на React и Next.js.

## 🚀 Технологии

- **React** (Functional components, Hooks)
- **Next.js 16** (App Router)
- **Tailwind CSS** для стилей
- **Lucide React** для иконок
- **TypeScript**

## 📦 Установка

```bash
# Установка зависимостей
pnpm install

# Запуск dev-сервера
pnpm dev
```

Приложение откроется на [http://localhost:3000](http://localhost:3000)

## 🎨 Структура интерфейса

### Sidebar (Узкий)

- Иконки навигации:
  - 🛒 Продажи
  - 📜 История
  - 📦 Склад
  - ⚙️ Настройки
- 🌐 Статус синхронизации (Online/Offline)

### Main Area (Grid layout)

**Левая колонка (60%)**

- Поиск товара сверху
- Категории товаров (табы)
- Сетка карточек товаров с ценой и картинкой

**Правая колонка (40%)**

- "Текущий чек"
- Список выбранных позиций с кнопками +/-
- Итоговая сумма:
  - Subtotal (Подытог)
  - Tax (НДС 20%)
  - Total (Итого)

**Нижняя панель (Checkout)**

- 💳 Оплата картой
- 💵 Наличные
- 👛 Комбинированная

## ✨ Функциональность

- ✅ Клик на товар добавляет его в чек
- ✅ Расчет итоговой суммы в реальном времени
- ✅ Изменение количества товаров (+/-)
- ✅ Удаление товаров из чека
- ✅ Фильтрация товаров по категориям
- ✅ Поиск товаров по названию
- ✅ Индикатор Online/Offline статуса
- ✅ Симуляция оплаты разными методами

## 🎨 Визуальный стиль

- **Тема**: Светлая
- **Стиль**: Профессиональный "Enterprise" вид
- **Шрифт**: Inter (латиница + кириллица)
- **Цвета**:
  - Primary Blue: `#2563eb`
  - Success Green: `#16a34a`
  - Gray scale для UI элементов

## 📁 Структура компонентов

```
app/
├── components/
│   ├── Sidebar.tsx          # Боковая навигация
│   ├── ProductCard.tsx      # Карточка товара
│   ├── ProductGrid.tsx      # Сетка товаров с поиском
│   ├── Cart.tsx             # Текущий чек
│   └── CheckoutPanel.tsx    # Панель оплаты
├── page.tsx                 # Главная страница
├── layout.tsx              # Root layout
└── globals.css             # Глобальные стили
```

## 🔧 Конфигурация

- `tailwind.config.ts` - настройки Tailwind CSS
- `next.config.ts` - конфигурация Next.js
- `tsconfig.json` - настройки TypeScript

## 📝 Mock данные

В приложении используются моковые данные для демонстрации функциональности:

- 16 товаров в различных категориях
- Категории: Кофе, Выпечка, Десерты, Еда, Чай, Напитки

## 🚦 Состояния

- **Online**: Система синхронизирована с центром
- **Offline**: Локальный режим работы

Переключение статуса доступно через кнопку в верхней панели.

## 📱 Адаптивность

Интерфейс адаптируется под разные размеры экрана благодаря Tailwind CSS responsive утилитам.
