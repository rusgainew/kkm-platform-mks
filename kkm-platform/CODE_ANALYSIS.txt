========== 1. АРХИТЕКТУРА ПРОЕКТА ==========

Структура слоев (Clean Architecture):
├── lib/api/         - HTTP-клиенты для backend (Axios + Fetch)
├── lib/hooks/       - Утилиты для hooks
├── hooks/           - React hooks (useCatalog, useUsers, useAuth...)
├── store/           - Zustand состояние (Catalog, Users, Auth, UI...)
├── features/        - Модули функциональности (каталог, счета, документы)
├── components/      - Переиспользуемые компоненты UI
├── app/[locale]/    - Next.js 16.1.1 страницы
└── app/api/         - Next.js API routes (прокси к backend)

Всего 235 файлов TS/TSX:
- lib/api: 8 файлов (catalog, users, documents, companies, invoices, bank-accounts, dashboard, client)
- hooks: 11 основных
- store: 10 Zustand stores
- features: ~25 компонентов
- components: 70 файлов UI
- app: 30 страниц
- остальное: утилиты, типы, константы
