## Быстрый старт (30 секунд)

### 1️⃣ Создание одного пользователя

```
UsersList → [Создать пользователя] → Форма
    ↓
Заполнить: email, имя, фамилия, роль, пароль
    ↓
Клик [Создать пользователя]
    ↓
✅ Готово!
```

**Требования пароля:** 8+ символов, ЗАГЛАВНАЯ, строчная, 123, !@#$

### 2️⃣ Импорт массово из CSV

```
UsersList → [Импорт] → Загрузить CSV
    ↓
Формат:
  email,first_name,last_name,password,role
  john@ex.com,John,Doe,Pass123!,cashier
    ↓
✅ Автоматическое создание!
```

### 3️⃣ Экспорт в CSV

```
UsersList → [Экспортировать CSV] → Скачать файл
    ↓
✅ Готов для Excel/Sheets
```

/users                           # Список пользователей

## Валидация

### Email

```
✅ user@example.com
❌ invalid-email
❌ user@  (уже зарегистрирован)
```

### Пароль

```
✅ SecurePass123!
  ├─ 8+ символов ✓
  ├─ Заглавная S ✓
  ├─ строчная ecurea ✓
  ├─ цифра 123 ✓
  └─ спецсимвол ! ✓

❌ weak (слишком короткий)
❌ ONLYUPPERCASE (без прописных)
```

### Роль

```
Cashier  (🎫 кассир)
Manager  (👔 менеджер)
Admin    (👑 администратор)
```

## Ошибки и решения

| Ошибка                              | Решение                                          |
| ----------------------------------- | ------------------------------------------------ |
| Email уже зарегистрирован           | Используйте другой email                         |
| Пароль не соответствует требованиям | Добавьте: заглавную, строчную, цифру, спецсимвол |
| У вас нет прав                      | Требуется роль Manager или выше                  |
| Некорректный CSV                    | Скачайте шаблон и заполните его                  |
| Ошибка сети                         | Проверьте интернет, перезагрузитесь              |

## Примеры CSV

### Правильный формат

```csv
email,first_name,last_name,password,role
john.doe@example.com,John,Doe,SecurePass123!,cashier
jane.smith@example.com,Jane,Smith,SecurePass456!,manager
bob.johnson@example.com,Bob,Johnson,SecurePass789!,admin
```

### Неправильный формат

```csv
❌ john@ex.com,John,Doe,weak,cashier  (пароль слабый)
❌ john@ex.com,John,,SecurePass1!,     (фамилия пуста)
❌ invalid,John,Doe,SecurePass1!       (email неправильный)
```
