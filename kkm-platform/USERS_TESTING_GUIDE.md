## Шаг 3: Создание пользователя

### Способ 1: Через кнопку в списке

1. На странице `/users` нажмите "Создать пользователя"
2. Перейдёте на `/users/create`

### Способ 2: Прямая навигация

Откройте в браузере: `http://localhost:3000/users/create`

### Заполнение формы

Заполните форму:

```
Email:        test@example.com
Имя:          Иван
Фамилия:      Иванов
Пароль:       Test123456!
Роль:         Менеджер
```

**Проверки валидации**:

- ✅ Попробуйте ввести пароль без заглавной буквы → видите требование
- ✅ Попробуйте ввести email без @ → видите ошибку
- ✅ Попробуйте оставить имя пустым → видите ошибку

**Отправка**:

- Нажмите "Создать пользователя"
- ✅ Увидите зелёное сообщение об успехе
- ✅ Через 2 секунды перенаправитесь на `/users`
- ✅ Новый пользователь должен появиться в списке

## Шаг 4: Редактирование пользователя

### Способ 1: Через кнопку в списке

1. На странице `/users` нажмите кнопку 🔵 Edit (первая кнопка) любого пользователя
2. Перейдёте на `/users/[id]/edit`

### Способ 2: Прямая навигация

`http://localhost:3000/users/1/edit` (замените 1 на реальный ID)

### Редактирование данных

На форме редактирования:

- Форма предзаполнена текущими данными
- Изменения отслеживаются автоматически
- Кнопка "Сохранить" активна только если есть изменения

**Тестирование**:

1. Измените имя пользователя
2. ✅ Кнопка сохранения становится активной
3. Нажмите "Сохранить"
4. ✅ Увидите зелёное сообщение об успехе
5. ✅ Через 2 секунды перенаправитесь на `/users`
6. ✅ Изменение отражено в таблице

## Шаг 7: Импорт CSV

1. На странице `/users` нажмите "Импорт"
2. Перейдёте на `/users/import`

### Подготовка CSV файла

**Способ 1: Скачать шаблон**

- На странице импорта есть кнопка "Скачать шаблон CSV"
- Откроется файл с колонками: `email,first_name,last_name,password,role`

**Способ 2: Создать вручную**

Создайте файл `users.csv`:

```csv
email,first_name,last_name,password,role
user1@example.com,John,Doe,Test123456!,cashier
user2@example.com,Jane,Smith,Test123456!,manager
user3@example.com,Bob,Johnson,Test123456!,cashier
```

### Загрузка файла

1. Выберите CSV файл
2. ✅ Видите предпросмотр данных с валидацией
3. Каждая строка проверяется:
   - Email формат
   - Пароль требования
   - Роль валидность
4. Нажмите "Импортировать"
5. ✅ Видите прогресс импорта
6. ✅ Видите результат: сколько успешно, сколько ошибок
7. ✅ Новые пользователи появляются в списке

---

## Шаг 8: Экспорт CSV

1. На странице `/users` нажмите "Экспортировать CSV"
2. ✅ Файл автоматически скачается
3. Имя файла: `users_export_YYYY-MM-DD.csv`
4. ✅ В файле все пользователи из текущего списка
