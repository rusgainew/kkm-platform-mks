## Создание пользователя

### Путь: `/users/create`

Страница для создания одного пользователя с полной валидацией формы.

### Компоненты

**`features/users/components/UserCreateForm.tsx`**

- Форма создания пользователя
- Поля: email, имя, фамилия, роль, пароль
- Валидация в реальном времени
- Отображение требований пароля

### Функции

#### Email

- ✅ Обязателен
- ✅ Валидация формата (RFC 5322)
- ✅ Проверка на уникальность (на стороне API)

#### Пароль

Требования (5 пунктов):

- ✅ Минимум 8 символов
- ✅ Заглавная буква (A-Z)
- ✅ Строчная буква (a-z)
- ✅ Цифра (0-9)
- ✅ Спецсимвол (!@#$%^&\*...)

#### Роль

- 🎯 **Cashier** (Кассир) - Может работать с кассой
- 🎯 **Manager** (Менеджер) - Может управлять магазином
- 🎯 **Admin** (Администратор) - Полный доступ к системе

### Обработка ошибок

| Ошибка         | Сообщение                                          |
| -------------- | -------------------------------------------------- |
| Email занят    | "Email уже зарегистрирован в системе"              |
| Слабый пароль  | "Пароль не соответствует требованиям безопасности" |
| Нет доступа    | "У вас нет прав для создания пользователей"        |
| Не авторизован | "Вы не авторизованы. Пожалуйста, перезагрузитесь"  |
| Ошибка сети    | "Ошибка сети. Проверьте подключение к интернету"   |

### Использование

```typescript
import UserCreateForm from "@/features/users/components/UserCreateForm";

export default function CreateUserPage() {
  return <UserCreateForm />;
}
```

## Импорт пользователей

### Путь: `/users/import`

Страница для массового создания пользователей через CSV файл.

### Компоненты

**`features/users/components/BulkUserImport.tsx`**

- Загрузка CSV файла
- Парсинг и валидация данных
- Прогресс импорта
- Отчёт об ошибках

### Формат CSV

```csv
email,first_name,last_name,password,role
john@example.com,John,Doe,SecurePass123!,cashier
jane@example.com,Jane,Smith,SecurePass456!,manager
bob@example.com,Bob,Johnson,SecurePass789!,admin
```

### Требования к данным

| Поле       | Обязательное | Требования                                          |
| ---------- | ------------ | --------------------------------------------------- |
| email      | ✅           | Валидный email                                      |
| first_name | ✅           | Минимум 1 символ                                    |
| last_name  | ✅           | Минимум 1 символ                                    |
| password   | ✅           | 8+ символов, прописная, строчная, цифра, спецсимвол |
| role       | ❌           | cashier, manager или admin                          |

### Процесс импорта

1. **Выбор файла** - выберите CSV файл
2. **Парсинг** - файл парсится в памяти
3. **Валидация** - каждая строка проверяется
4. **Создание** - валидные строки создаются через API
5. **Отчёт** - выводится результат (успехи и ошибки)

### Результат

```
✅ Успешно: 2
❌ Ошибок: 1

Ошибки:
Строка 3: Email уже зарегистрирован в системе
```

### Скачивание шаблона

Кнопка "Скачать шаблон CSV" генерирует пример файла с предустановленными колонками.

## Валидация

### Фронтенд

Все валидации выполняются в реальном времени:

- Email формат
- Требования пароля
- Обязательные поля
- Роль из списка допустимых

### Бэкенд

Валидация на уровне API Gateway:

- Проверка прав доступа (только manager и выше)
- Уникальность email
- Требования пароля
- Валидация ролей

### Сообщения об ошибках

Ошибки парсятся и преобразуются в понятные сообщения:

```typescript
const parseApiError = (error: unknown): string => {
  // Специфичные для KKM обработки ошибок
  if (message.includes("email")) return "Email уже зарегистрирован";
  if (message.includes("permission")) return "Нет прав доступа";
  // ...
};
```

## API Интеграция

### Endpoints

#### Создание пользователя

```
POST /users
Content-Type: application/json
Authorization: Bearer <token>

{
  "email": "user@example.com",
  "password": "SecurePass123!",
  "first_name": "John",
  "last_name": "Doe"
}
```

#### Получение списка пользователей

```
GET /users-query
Authorization: Bearer <token>
```

```typescript

  "user": {
    "user_id": "uuid",
    "email": "john@example.com",

    "last_name": "Doe",
    "role": "cashier",
    "status": "active",
    "is_active": true,
    "created_at": 1705315200,
    "updated_at": 1705315200
  }
}
```

## FAQ

### Как изменить требования пароля?

Отредактируйте константу `PASSWORD_REQUIREMENTS` в `UserCreateForm.tsx`:

```typescript
const PASSWORD_REQUIREMENTS = [
  { label: "8 символов", regex: /.{8,}/ },
  { label: "Заглавная буква", regex: /[A-Z]/ },
  // ...
];
```

### Как добавить новую роль?

1. Обновите константу `ROLES` в `UserCreateForm.tsx`
2. Обновите типы в `lib/api/users.ts`
3. Обновите валидацию в `BulkUserImport.tsx`

### Почему импорт медленный?

CSV импорт создаёт пользователей последовательно (не параллельно) для контроля ошибок. Используйте бэкенд API для массовых импортов.

## Поддержка

При возникновении проблем:

1. Проверьте консоль браузера на ошибки
2. Убедитесь, что вы авторизованы как manager или admin
3. Проверьте формат CSV (используйте скачанный шаблон)
4. Свяжитесь с техподдержкой
