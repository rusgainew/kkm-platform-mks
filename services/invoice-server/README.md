# Invoice Server

Микросервис для управления электронными счетами-фактурами (ЭСФ) в системе ККМ.

## Возможности

- ✅ Создание, обновление счетов-фактур
- ✅ Подписание счетов электронной подписью
- ✅ Принятие/отклонение счетов покупателем
- ✅ Отзыв (аннулирование) счетов
- ✅ Список счетов с пагинацией и фильтрацией
- ✅ Event-driven архитектура (RabbitMQ)
- ✅ Полная observability (метрики, трассировка, логирование)
- ✅ Health checks

## Entities

### Invoice (Счет-фактура)

- Основной документ системы ЭСФ
- Типы: СФ-РЕ (реализация), СФ-ПР (приобретение), КСФ (корректировочный)
- Жизненный цикл: Черновик → Отправлено → Одобрено/Отклонено → Подписано → (Отозвано)

### InvoiceDetail (Позиция счета)

- Строка товара/услуги в счете
- Содержит: наименование, количество, цену, налоги
- ТНВЭД/ГКЭД классификация

### FinancialData (Финансовые данные)

- Суммы, налоги, сборы
- Банковские реквизиты
- Платежная информация

### InvoiceContract (Контрактные данные)

- Информация о договоре
- Условия оплаты и поставки

## Запуск

```bash
# С Docker Compose
docker-compose up -d invoice-server

# Локально
go run cmd/main.go
```

## Endpoints

- **gRPC**: `:50053`
- **Metrics**: `:9093/metrics`
- **Health**: `:9093/health`

## API

### InvoiceCommandService

- `CreateInvoice` - создание счета
- `UpdateInvoice` - обновление счета
- `SignInvoice` - подписание счета
- `AcceptOrRejectInvoice` - принятие/отклонение
- `RevokeInvoice` - отзыв счета

### InvoiceQueryService

- `ListInvoices` - список счетов с пагинацией
- `ListInvoiceDetails` - список позиций счета

## События

- `invoice.created` - счет создан
- `invoice.updated` - счет обновлен
- `invoice.signed` - счет подписан
- `invoice.accepted` - счет принят
- `invoice.rejected` - счет отклонен
- `invoice.revoked` - счет отозван
