# Генератор пользователей

Скрипт для генерации 10000 пользователей с реальными именами и фамилиями.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование

```bash
python gen_user.py
```

## Что делает скрипт

1. Генерирует 10000 пользователей с:
   - UUID в качестве ID
   - Реальными именами и фамилиями (50% русские, 50% английские)
   - Email на основе имени и фамилии
   - Bcrypt хэшем пароля
   - Случайным статусом (85% active, 10% inactive, 5% suspended)
   - Случайной ролью (90% user, 2% admin, 5% manager, 3% moderator)
   - Timestamp created_at/updated_at

2. Выводит статистику по сгенерированным пользователям

3. Спрашивает подтверждение и вставляет данные в PostgreSQL

## Примечания

- Скрипт использует `ON CONFLICT (email) DO NOTHING`, поэтому повторный запуск безопасен
- Вставка происходит пакетами по 1000 записей для оптимизации
- Используются библиотеки Faker для генерации реальных имен
